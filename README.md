# Steps to compile and run the application.

### Initial Set-up
Using jdbc, 42.7.14 from:
https://jdbc.postgresql.org/download/

Using openjdk-21.

Change variables URL, USER, PASSWORD to match your configuration.

### Running the application

Compile and run with
```
javac -cp postgresql-42.7.3.jar StudentApp.java
java -cp .:postgresql-42.7.3.jar StudentApp
```

Choose CRUD operations to run entering integers 1-5 and following the provided instructions for input.
